# Language Translation Tool

## Project Description

This project is a Language Translation Tool developed using Python and Tkinter.

The application allows users to translate text between multiple languages using Google Translator API through the Deep Translator library.

## Features

- Auto Language Detection
- Multiple Language Support
- User Friendly Interface
- Copy Translated Text
- Clear Input and Output
- Real Time Translation

## Technologies Used

- Python
- Tkinter
- Deep Translator
- Pyperclip

## How To Run

1. Install dependencies

pip install -r requirements.txt

2. Run the application

python translator.py
